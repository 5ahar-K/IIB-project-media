Supplementary animations for Part IIB project: Optical Wireless Communication and Station-Keeping for UAVs (Cambridge Engineering, 2025). Includes animated visualisation of closed-loop beam tracking using the biased (uncalibrated) clipped-centroid estimator with a pure integrator controller over a 2-second run. The blue dot shows the true beam-centre position on the detector plane and the orange dot shows the estimated beam-centre position; the right panel tracks the cumulative RMSE over time.
